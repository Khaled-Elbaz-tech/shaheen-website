Ola Magdy — Architecture Portfolio

Redesigned website, 28 September 2026.

The dist folder contains the publishable website: homepage, full project index, 27 collection/case-study pages, styles, scripts, fonts and project imagery. Serve dist through a web server; paths are relative to the site root.

For content editing, update content.json and project-register.json. Run build.py with Python 3 to regenerate the HTML. Edit dist/style.css and dist/site.js to adjust design and interactions. Images and their size/source metadata are in dist/assets and assets.json.

27 pages and 81 index links describe collections and programmes; they are not a count of independent project commissions. See the separate Project Coverage Audit for the master-list reconciliation, missing source folders and naming questions.
